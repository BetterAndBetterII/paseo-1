# desktop_markdown_rendering v1

Initial frozen release. Payloads are deterministic ASCII generated by the mock load-test provider.
Every case uses 512-byte provider chunks at a 1ms interval and records the final rendered-text hash
so implementation candidates must settle to the same visible content as baseline.

The `anchor` split covers the known dominant classes: a one MiB growing single block, an actively
highlighted open TypeScript fence, and mixed Markdown with stable blocks. The `main` split adds the
full workload and size matrix.
